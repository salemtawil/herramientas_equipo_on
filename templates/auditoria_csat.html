Cómo se calcula

CSAT real = positivas / calificaciones válidas ({{ metricas.total_respuestas }} respuestas: {{ metricas.positivos }} positivas, {{ metricas.neutrales }} neutrales, {{ metricas.negativos }} negativas). CSAT ajustado = positivas / (válidas menos los negativos confirmados como «No fue culpa del agente»). «Sí fue culpa del agente» y «Dudoso» siguen contando.

Cómo funciona

Elige el período arriba y pulsa «Traer encuestas». La auditoría avanza en cuatro pasos.

  1. 1. EncuestasSe traen de Chatwoot las encuestas del período.
  2. 2. La IA revisaPropone, para cada negativo, si fue culpa del agente.
  3. 3. Tú confirmasDecides en cada ficha; solo tus confirmaciones cambian el CSAT ajustado.
  4. 4. ResultadoCSAT real vs ajustado, por agente y descargas para el informe.
